# Support

Check Make is an open, community-oriented project maintained on a best-effort
basis. There is no guaranteed response time, compatibility commitment, or
service-level agreement.

Use GitHub Issues for reproducible bugs and focused feature proposals. Before
opening an issue:

1. Check the latest release notes and existing issues.
2. Include the Check Make version, operating system, printer, slicer and slicer
   version where relevant.
3. Describe expected and actual behavior and provide minimal reproduction
   steps.
4. Remove API keys, personal models, private paths, serial numbers and other
   sensitive information from logs and attachments.

General 3D-printing advice, printer repair, slicer support, and validation of
safety-critical parts are outside the project's support scope.

Security reports must follow [SECURITY.md](SECURITY.md), not a public issue.
