# Check Make GUI concept v2 — generation prompt

Built-in image generation was used. GUI concept v1 supplied the base composition, while the canonical Check Make brand reference, symbol, and wordmark supplied the visual identity.

## Prompt

Use case: ui-mockup

Create an updated, high-fidelity macOS Check Make desktop-app concept. Preserve the successful large 3D viewport and right recommendation hierarchy from concept v1, but replace the left navigation menu with a persistent project-context panel for the current model, printer, material, and analysis mode.

Remove the black title bar. Use a slim native warm-white macOS toolbar with traffic-light controls, the canonical checked-cube symbol, and the canonical `CHECK / MAKE` wordmark. Add only a thin Blueprint Navy construction line beneath it. Move navigation into compact horizontal tabs: “Overview”, “Analysis”, “Geometry”, “Results”, and “Export”.

The left `PROJECT` panel contains:

- `MODEL`: “mounting-bracket.stl”, “STL · 62.4 mm high”, and “Replace”.
- `PRINTER`: “Creality Ender-3 V3 SE” and “220 × 220 × 250 mm”.
- `MATERIAL`: “PETG” and “0.4 mm nozzle”.
- `ANALYSIS`: “Local + rules” and “Evidence-linked”.
- An “Open project…” button and “Saved” status.

Retain the gray mounting bracket on a Blueprint Navy build plate with subtle Technical Cyan grid lines, Make Green plate edge, XYZ axes, the controls “Selected”, “Risk map”, and “Compare”, plus “62.4 mm height”, “4 mesh parts”, and “3 overhang regions”.

Retain the recommendation panel with “Review required”, “Ready after 2 decisions”, three top recommendations, the load-direction confirmation warning, key settings, the “Review recommendation” action, Core 3MF, and the five supported slicer exports. Retain the bottom evidence strip: “Local geometry measured”, “Rules are evidence-linked”, and “No structural simulation”.

Use the canonical brand palette: Make Green `#35C98B`, Action Green `#168866`, Blueprint Navy `#073A60`, Technical Cyan `#8DDCFF`, Technical Ink `#171A19`, Warm White `#F7F7F2`, and Cool Canvas `#F3F5F4`. Make Green is reserved for checks, active states, and highlights; use Action Green for accessible buttons and small text.

The result should feel like a premium Figma-quality native macOS utility with precise icons, modest corner radii, crisp typography, subtle borders, restrained shadows, and generous clear space around the canonical symbol. Avoid a black title bar, dark theme, generic cube logo, sidebar navigation list, gradients on brand marks, fake readiness scores, and invented capabilities.
